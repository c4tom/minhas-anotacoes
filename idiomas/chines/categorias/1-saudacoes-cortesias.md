### Saudações e Cortesias

#### Saudações

* **Olá** : 你好 (nǐ hǎo)
* **Bom dia** : 早上好 (zǎo shàng hǎo)
* **Boa tarde** : 下午好 (xià wǔ hǎo)
* **Boa noite** : 晚上好 (wǎn shàng hǎo)
* **Oi (informal)** : 嗨 (hāi)
* **Tudo bem?** : 你好吗？(nǐ hǎo ma?)

#### Despedidas

* **Adeus** : 再见 (zài jiàn)
* **Até logo** : 回头见 (huí tóu jiàn)
* **Até amanhã** : 明天见 (míng tiān jiàn)
* **Cuide-se** : 保重 (bǎo zhòng)
* **Boa noite (ao despedir-se)** : 晚安 (wǎn ān)

#### Expressões de Cortesia

* **Por favor** : 请 (qǐng)
* **Obrigado** : 谢谢 (xiè xie)
* **Muito obrigado** : 非常感谢 (fēi cháng gǎn xiè)
* **De nada** : 不客气 (bú kè qi) / 不用谢 (bú yòng xiè)
* **Desculpe** : 对不起 (duì bu qǐ)
* **Com licença** : 劳驾 (láo jià) / 打扰一下 (dǎ rǎo yí xià)
* **Posso ajudar?** : 我能帮忙吗？(wǒ néng bāng máng ma?)
* **Sim** : 是的 (shì de)
* **Não** : 不是 (bú shì)
